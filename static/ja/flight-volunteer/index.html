保護犬・フライトボランティア

フライトボランティア引き渡しキット

韓国→米国／カナダ（EN+KO）、メキシコ→米国／カナダ（EN+ES）の2言語空港カード。CFIAの商業／個人の区分とCDC Dog Import Formに重点を置いています。

重要な法令順守上の注意

  • カナダ（CFIA）：輸入区分は、付き添い者がボランティアであるかどうかだけでなく、所有権、輸入者、使用目的から判断します。CFIAには同伴ペットと同伴者のいないペットのための個人向けの手続きがあります。譲渡、一時預かり、移譲を目的とする犬は商業輸入にあたります。予約前に適用される条件をご確認ください。カナダは、CFIAの犬の狂犬病高リスク国リストに掲載された国からの商業目的の犬の輸入を、追って通知があるまで禁止しており、そのような輸入には輸入許可証が発行されません。輸送を引き受ける前に、CDCのリストではなくCFIAのリストをご確認ください。フライト前にCFIAの公式ガイダンスでご確認ください。
  • ボランティア：ボランティアであることは、輸入区分でも包括的な免除でもありません。米国では、APHIS Animal Careが再販売（輸入後の有料での譲渡を含む）を規制していますが、海外で譲渡され、さらに再販売されることなく飼い主に引き渡される犬はAWAの対象外としています。CDC、その他のAPHIS、州の要件は引き続き適用されます。カナダは独自の商業輸入の定義を用いています。
  • 米国（CDC）：ほぼすべての犬にCDC Dog Import Formの受領証が必要です。高リスク国と低リスク国で手続きが異なります。
  • メキシコ（SENASICA）：米国からメキシコへ渡航するペットの犬については、OISA／SENASICAの入国検査と、2026年8月3日から施行されているNWS検査書類の要件に従ってください。メキシコから米国に入国する犬には、別途ラセンウジバエ不在の証明が必要です。実際の出発地と移動の目的に応じた輸出要件をご確認ください。
