ペットとの旅行：獣医師が準備すべきこと

最終確認：2026年11月

このページは、犬や猫との海外旅行を計画している動物病院のスタッフと飼い主の方向けです。獣医学的な手順を通常必要な順序で示し、政府の公式ページとPetPolicyCheckの国別ガイドやルートガイドをご案内します。

入国規則は目的地が定めます。米国を出国するペットの輸出健康証明書は、USDA認定獣医師が作成し、裏書きが必要な場合は裏書きのために提出します。経由地、ペットが客室と貨物のどちらで移動するか、出発日を獣医師にお伝えください。APHIS — 米国から他国へペットを連れて行くをご覧ください。

以下はすべて、政府または規制当局が公表している公式規定です。予約や証明書の発行の前に、目的地の当局およびAPHISまたは同等の公的機関に最新の内容をご確認ください。

印刷用の動物病院向けチェックリストを以下に掲載しているほか、別途印刷しやすいA4シートもご用意しています。飼い主の方は、ペット旅行チェックリスト、Pet Travel Passport、狂犬病の抗体価カウントダウンもご利用いただけます。

獣医学的な手順（順番どおり）

1. マイクロチップ

目的地がチップを先に装着するよう定めている場合は、必要な狂犬病ワクチン接種の前に、マイクロチップでペットを識別してください。

  • 欧州委員会は、EU域外からEUに入国する犬、猫、フェレットにISO規格のマイクロチップを求めています。
  • 日本の動物検疫所は、指定地域以外（ハワイとグアムを除く米国本土）からの輸入について、1回目の狂犬病ワクチン接種の前に装着したISO規格のマイクロチップを求めています。
  • 韓国のAPQAは、生後90日未満の動物を含め、犬と猫にISO 11784/11785規格のマイクロチップを求めています。
  • CDCは、米国に入国する犬にマイクロチップを求めています。
  • GOV.UKは、英国に入国するペットにマイクロチップを求めています。

マイクロチップ番号は、狂犬病の証明書、抗体価の報告書、輸出健康証明書に記載されるとおり正確に記録してください。スキャナーでチップを読み取れない場合、書類が揃っているように見えても、目的地での確認で不合格になります。

2. 狂犬病ワクチン接種

目的地がその順序を求めている場合は、マイクロチップの装着後にワクチンを接種してください。

  • EU：生後12週以上で狂犬病ワクチンを接種し、初回接種後21日間待ってから旅行します。欧州委員会のガイドをご覧ください。
  • 英国：狂犬病ワクチン接種と、初回接種から21日の待機。英国にペットを連れて行くをご覧ください。
  • 日本（ハワイとグアムを除く米国本土を含む指定地域以外）：ペットが生後91日以上で1回目の狂犬病ワクチン接種、少なくとも30日後に2回目の接種。農林水産省 動物検疫所をご覧ください。
  • 米国への入国：犬は生後6か月以上である必要があります。CDC — 米国に犬を持ち込むをご覧ください。

製造元、ロット番号、接種日、有効期限を、証明書と一緒に持ち運ぶ記録に残してください。

3. 目的地が求める場合は、狂犬病の抗体価検査

中和抗体価検査がすべての到着地で必要なわけではありません。公式リストや検査機関の規則で定められている場合に必要です。

  • EU：発送国が実施規則（EU）2026/636に掲載されていない限り、狂犬病の抗体価検査が必要です。米国、カナダ、メキシコ、英国、日本は掲載されています。韓国は掲載されていません。欧州委員会の地域とEU域外国のリストをご覧ください。リストに掲載されていない国の場合、欧州委員会のガイドによると、採血は初回ワクチン接種の少なくとも30日後、かつ証明書の発行の90日以上前に行います。
  • 英国（グレートブリテン）：リストに掲載されていない国からのペットは、入国前に狂犬病の血液検査を受け、採血後3か月待つ必要があります。米国は掲載されています。韓国は掲載されていません。GOV.UK — 狂犬病の血液検査とどのペット旅行書類が必要かをご覧ください。
  • 日本（指定地域以外）：0.5 IU/ml以上の抗体価が必要で、採血日から180日間の待機があります。農林水産省 動物検疫所をご覧ください。その待機の計画には抗体価カウントダウンをご利用ください。
  • 韓国：狂犬病清浄国に分類されていない国から到着する生後90日以上の犬と猫には、承認された検査機関による0.5 IU/ml以上の狂犬病中和抗体の結果と、マイクロチップ番号と抗体価の結果を記載した政府の健康証明書が必要です。APQAをご覧ください。
  • 高リスク国から米国に入国する場合：過去6か月間に犬が犬の狂犬病の高リスク国にいた場合は、CDCの追加書類が必要です。米国でワクチンを接種した犬の場合、Certification of U.S.-Issued Rabies Vaccinationは犬が米国を出国する前に裏書きを受ける必要があり、さかのぼって発行することはできません。

過去6か月間、狂犬病清浄国または低リスク国のみに滞在していた犬は、CDCの書類が少ない手続きに従います：Dog Import Form、月齢、マイクロチップ、健康な外見。

4. 健康証明書と臨床検査

証明書の様式は到着地が指定します。診察する獣医師は、その様式が有効な間にペットを診察する必要があります。

  • EU：非商業目的の動物衛生証明書は、実施規則（EU）2026/705の附属書IIIです。欧州委員会のガイドによると、EUの入国審査まで10日間（船旅の場合はその期間を加算）有効で、その後はEU域内の移動について6か月間または狂犬病ワクチンの有効期限まで（いずれか早い方）有効です。APHISは2026年10月1日から新しいEUの非商業目的の証明書を求めています。APHIS — 米国からフランスへのペット旅行とドイツへのペット旅行をご覧ください。
  • EU（条虫、犬）：フィンランド、アイルランド、マルタ、北アイルランド、ノルウェーに入国する犬は、入国予定時刻の120時間前から24時間前までの間に、獣医師によるEchinococcus multilocularis（多包条虫）の駆虫を受ける必要があります。欧州委員会のガイドをご覧ください。
  • 英国（グレートブリテン）：USDA認定獣医師が発行するグレートブリテンのペット健康証明書。証明書の発行から10日以内（APHIS：APHISの裏書きから10日以内）に英国に入国します。GOV.UK — グレートブリテンのペット健康証明書とAPHIS — 米国から英国へのペット旅行をご覧ください。犬は、フィンランド、アイルランド、北アイルランド、マルタ、ノルウェーから直接来る場合を除き、到着の24時間以上120時間以内前にプラジクアンテル（またはEchinococcus multilocularisに効果が証明された同等の薬）の投与も必要です。GOV.UK — 犬の条虫の駆虫をご覧ください。
  • 日本：搭乗前10日以内の臨床検査、少なくとも40日前までの動物検疫所への事前届出、政府の裏書きを受けたForm AC（またはAPHISが認める代替書式）。農林水産省 動物検疫所とAPHIS — 米国から日本へのペット旅行をご覧ください。
  • 韓国：マイクロチップ番号と、抗体価検査が必要な場合はその結果を記載した政府の健康証明書。APHIS：USDA認定獣医師がVEHCSを通じて証明書を発行し、APHISがインクで署名してエンボス加工を施します。原本はペットと一緒に移動します。APQAとAPHIS — 米国から韓国へのペット旅行をご覧ください。
  • メキシコ（米国からの犬）：入国前5日以内にUSDA認定獣医師が署名したラセンウジバエの検査証明書（2026年8月3日から施行）。この書式にはAPHISの裏書きは不要です。SENASICAがOISAの事務所で犬を検査し、その後輸入証明書（CZI）を発行します。APHIS — 米国からメキシコへのペット旅行をご覧ください。メキシコから米国に戻る犬には、SENASICAが承認した獣医師によるラセンウジバエ非感染証明書（検査は移動前5日以内）とCDC Dog Import Formが必要です。
  • カナダ：輸入要件は、出発国、動物の年齢、輸入の目的、動物が飼い主と一緒に移動するかどうかによって異なります。患者に適用される様式は、CFIA — 犬との旅行とAPHIS — 米国からカナダへのペット旅行でご確認ください。

5. APHIS（VEHCS）または公式当局による裏書き

米国を出国するペットの場合、USDA認定獣医師がVEHCSで証明書を作成して提出します。発行には認定獣医師の電子署名が認められています。その後APHISがインクと電子のどちらで証明書に裏書きするかは、引き続き目的地によって異なります：

  • 英国、フランス、ドイツ、韓国：APHISがインクで署名してエンボス加工を施し、紙の証明書の原本がペットと一緒に移動します。
  • 日本：APHISが犬と猫の証明書に電子的に裏書きします。印刷したコピーを携帯してください。
  • メキシコ（2026年8月3日からのラセンウジバエに関する犬の書式）：APHISの裏書きは不要。

APHISは裏書きの料金を別途公表しています。最新の金額はそのページでご確認ください。

ペットが他国から出国する場合は、その国の公式の獣医当局が証明書に裏書きします。カナダでは、CFIAが、免許を持つ獣医師が発行し、その後CFIAの公式獣医師が裏書きする輸出証明書について説明しています。CFIA — 犬との旅行をご覧ください。

  • 該当する場合は、出国前に裏書きを受けた米国の狂犬病の証明書を含む、高リスク国に関する書類

よくある質問

すべての目的地で狂犬病の抗体価検査が必要ですか？

いいえ。EUは、実施規則（EU）2026/636に掲載された国（米国、カナダ、メキシコ、英国、日本を含む）について抗体価検査を免除しています。英国（グレートブリテン）もリスト掲載国の表を使用しており、米国は掲載され、韓国は掲載されていません。日本は、指定地域以外から来るペットに抗体価検査と180日間の待機を求めています。韓国は、狂犬病清浄国以外から来る生後90日以上の犬と猫に、0.5 IU/ml以上の抗体価を求めています。

日本の場合、いつ準備を始めるべきですか？

指定地域以外から来るペットの場合は、公式の待機期間のうち最も長いものから計画してください：1回目の狂犬病ワクチン接種前のISO規格のマイクロチップ、2回の狂犬病ワクチン接種（1回目は生後91日以上、2回目は少なくとも30日後）、0.5 IU/ml以上の抗体価、採血から180日間の待機、少なくとも40日前までの動物検疫所への届出、搭乗前10日以内の臨床検査。

飼い主がAPHISの裏書きの手続きを行うことはできますか？

いいえ。米国を出国するペットの場合、USDA認定獣医師が証明書を作成し、VEHCSを通じて提出します。目的地が裏書きを求めている場合、APHISが裏書きします。VEHCSをご覧ください。

猫はCDC Dog Import Formを使用しますか？

いいえ。APHISによると、米国に入国する猫にはCDC Dog Import Formは使用しません。健康に見える必要があり、州、航空会社、ハワイ、グアムの規則が適用される場合があります。

すでにこの書類手続きを行っている動物病院はどこで探せますか？

ペット旅行の証明書を扱う米国の動物病院と提携獣医師をご覧ください。

免責事項

このページは情報提供のみを目的としています。これは獣医学的、法的、旅行上の助言ではありません。到着地の規則、証明書の様式、待機期間は変わります。証明書を発行する前や旅行の前に、診察する獣医師、APHIS、CFIAまたはそれに相当する公的機関、到着国の政府にすべての手順をご確認ください。
