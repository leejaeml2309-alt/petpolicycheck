ペットと旅行するための獣医情報

最終確認：2026年11月

このページは、ほとんどの到着地が獣医師に準備を求める健康書類の出発点です：マイクロチップ、狂犬病ワクチン接種、必要な場合の狂犬病の抗体価検査、公的機関による裏書きが必要な場合がある健康証明書。

入国規則は到着地が定めます。米国を出国するペットについては、USDA認定獣医師が輸出証明書を作成し、裏書きが必要な場合は裏書きのために提出します。経由地、ペットが機内か貨物か、出発日を獣医師に伝えてください。APHIS — 米国から他国へペットを連れて行くをご覧ください。

動物病院での手順は順を追って獣医師が準備すべきことに掲載しています。以下の国別、地図、ルートのページで、到着地ごとの正確な規則をご確認いただけます。証明書を発行する前や旅行の前に、到着地の当局とAPHIS、またはそれに相当する公的機関で最新の内容をご確認ください。

米国の動物病院リスト

米国クリニックのリストには、ペット旅行や健康証明書に関するサービスを提供しているとみられる、51州の85の動物病院を州別に掲載しており、州で絞り込めます。情報提供のための掲載で、提携ではありません。サービス、USDAの認定、料金は必ず各動物病院に直接ご確認ください。

マイクロチップ

ほとんどの到着地ではペットをマイクロチップで識別する必要があり、その順序が規則に含まれる場合は、多くの到着地で狂犬病ワクチン接種の前にチップを装着しておく必要があります。

  • 欧州委員会は、EU域外からEUに入国する犬、猫、フェレットにISO規格のマイクロチップを求めています。
  • 日本の動物検疫所は、指定地域以外からの輸入について、最初の狂犬病ワクチン接種の前に装着したISO規格のマイクロチップを求めています。
  • 韓国のAPQAは、ISO 11784/11785のマイクロチップを求めています。
  • CDCは、米国に入国する犬にマイクロチップを求めています。
  • GOV.UKは、英国に入国するペットにマイクロチップを求めています。

スキャナーに表示される番号は、その後のすべての書類（狂犬病の証明書、抗体価検査の報告書、輸出健康証明書）と一致する必要があります。

狂犬病ワクチン接種

到着地がその順序を求める場合は、マイクロチップの後にワクチンを接種してください。

  • 欧州連合：生後12週以上でワクチン接種、その後初回接種から21日の待機。欧州委員会のガイドをご覧ください。
  • 英国：狂犬病ワクチン接種と、初回接種から21日の待機。英国にペットを連れて行くをご覧ください。
  • 米国への入国：犬は生後6か月以上である必要があります。CDC — 米国に犬を持ち込むをご覧ください。米国に入国する猫はCDC Dog Import Formを使用しません。健康に見える必要があり、州、航空会社、ハワイ、グアムの規則が適用される場合があります。APHIS — 猫をご覧ください。

その他の到着地は独自の月齢と接種スケジュールを定めています。上記のリストをすべてとみなさず、その旅行の国別またはルート別のページをご覧ください。

狂犬病の抗体価検査

中和抗体価検査がすべての到着地で必要なわけではありません。公式リストや検査機関の規則で定められている場合に必要です。

  • 欧州連合は、米国、カナダ、メキシコ、英国、日本を含む、実施規則（EU）2026/636に掲載された国について検査を免除しています。韓国は掲載されていません。欧州委員会のリストをご覧ください。非リスト国について、欧州委員会のガイドでは、初回接種から少なくとも30日後に採血し、証明書発行の90日以上前であることとしています。
  • 英国はリスト掲載国の表に基づき、血液検査と採血から3か月の待機が必要かどうかを判断します。GOV.UK — which pet travel documentと狂犬病の血液検査をご覧ください。
  • 日本では、指定地域以外から来るペットについて、0.5 IU/ml以上の結果と採血から180日の待機が必要です。農林水産省 動物検疫所と抗体価のカウントダウンをご覧ください。
  • 韓国は、狂犬病清浄国に分類されていない国から到着する生後90日以上の犬と猫について、0.5 IU/ml以上の結果を求めています。APQAをご覧ください。

健康証明書と裏書き

証明書の様式は到着地が指定します。診察する獣医師は、その様式が有効な間にペットを診察する必要があります。

米国を出国するペットについては、USDA認定獣医師がVEHCSで証明書を作成・提出します。その後APHISがインクで裏書きするかデジタルで裏書きするかは到着地によって異なります。紙の原本として携帯する証明書もあれば、APHISの裏書きが一切不要な到着地もあります。

ペットが他の国から出国する場合は、その国の公的な獣医当局が証明書に裏書きします。カナダの輸入規則は、出発地、月齢、目的、飼い主と一緒に移動するかどうかによって異なります。CFIA — 犬と旅行するをご覧ください。

公的機関が公表している一般的な有効期間には、EUの入国審査まで10日、英国への入国まで10日、日本の場合は搭乗前10日以内の臨床検査があります。欧州委員会のガイド、英国のペット健康証明書、農林水産省 動物検疫所をご覧ください。患者に適用される様式は、国別またはルート別のページでご確認ください。

到着直前の寄生虫駆除を求める到着地もあります。英国に入国する犬、またはEU域外からフィンランド、アイルランド、マルタ、北アイルランド、ノルウェーに入国する犬は、24～120時間の期間内に獣医師によるEchinococcus multilocularisの駆除が必要です。GOV.UK — 犬の条虫駆除と欧州委員会のガイドをご覧ください。

動物病院での準備

抗体価検査の待機期間に間に合うよう、早めにUSDA認定獣医師（米国外では公的に同等の獣医師）を予約してください。ペットの最新の記録と、正確な到着地、経由地、旅行日、機内か貨物かの予定をお持ちください。APHISは、証明書が旅程と一致するよう、飼い主にこれらの詳細を伝えるよう求めています。

旅行用の証明書に対応している動物病院を探すには、米国の動物病院と提携獣医師をご覧ください。

USDA認定獣医師を探すには、USDA Vet Finderをご覧ください。
