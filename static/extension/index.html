Free Chrome Extension · Manifest V3

“Pets Allowed?” — Instant airline & hotel pet rules while you browse

When you open an airline or hotel site, a bottom-right pill and a 1-click popup show cabin vs hold, fees, carrier dimensions, weight limits, and nearby vet context — with zero tracking. Permissions: activeTab + storage only.

Download .zip (v1.0.1)

Package v1.0.1: americanairlines.com host matches, Air Canada fee shows as CA$50–60, Marriott labeled brand-level (rules vary per hotel).

Browse unpacked files

Install in 3 steps (while Chrome Web Store review is queued)

  1. Download & unzip the package above (folder pets-allowed-mv3/).
  2. Open chrome://extensions and enable Developer mode.
  3. Click Load unpacked and select the unzipped pets-allowed-mv3 folder.

Covers 50+ airline & hotel / OTA URL patterns. Data mirrors PetPolicyCheck’s verified airline and hotel sheets. Official sources always linked inside the popup.

What you see

  • Floating pill: e.g. Pets OK · $150 · 18×11×11″
  • Airline view: dogs/cats cabin vs hold, fees, under-seat dimensions
  • Hotel view: fees, weight limits, nearby 24/7 vet from our clinics directory
  • CTAs to Pet Travel Passport checklist, city guides, and updates
