Qantas Freightでペットとオーストラリアから米国へ

ルート計画用の確認済みスナップショット。航空会社の情報はQantas Freightの公式ペットページによるものです（2026年11月14日確認）。米国入国の概要はCDCとAPHISを引用しています。

渡航先の入国要件の概要

米国（CDC／APHIS）：オーストラリアはCDCの犬の狂犬病高リスク国リストに含まれていません。過去6か月間に狂犬病清浄国または低リスク国のみに滞在した犬には、CDC Dog Import Formの受領書（無料）、読み取り可能なマイクロチップ、生後6か月以上であること、健康に見えることが必要です。CDCのフォームは猫には適用されません。猫の入国はAPHISとCBPの公式ページでご確認ください。オーストラリアの輸出手続きはDAFFの公式ページでご確認ください。

Qantas Freight

  • ペットの輸送方法：公式ページによると、オーストラリア発のペットはペット輸送の専門業者を通じて予約する必要があり、専門業者が出発地、経由地、到着地の要件を調整します。この国際線の経路では、通常ペットを一般の受託手荷物として扱うことはできません。
  • CDCのお知らせ：国際ページでは、米国に輸送される犬に関する現行の方針が示され、CDCのウェブサイトが案内されています。旅行前にCDC Dog Import Formを提出し、受領書を携帯してください。
  • 空港の制限：Qantas Freightは、一時的な空港ごとの受け入れ停止と現地の規則を公式の国際ペットページで公表しています。予約前にそのページをご確認ください。季節ごとの日付は変わります。
  • 月齢・健康・品種：Freightのページで公表されている国際線と同じ条件です：生後12週未満の子犬・子猫は不可。鎮静状態、体調不良、けが、妊娠後期、攻撃的に見えるペットは不可。短頭種は専門の予約が必要。現役のレース用グレーハウンドは輸送されません。
  • 公表されている機内料金： 該当なし — Qantasは、オーストラリア発のペットについて専門業者／Freightでの予約を求めています。当サイトは貨物料金を推測で記載しません。

FAQ

オーストラリアから米国へ出国する犬に、CDCは何を求めていますか？

過去6か月間に、CDCが犬の狂犬病清浄国または低リスク国とする国（オーストラリアは高リスクリストに含まれていません）のみに滞在した犬の場合：CDC Dog Import Formの受領書、マイクロチップ、生後6か月以上、健康に見えること。出発前にCDCの公式ページでご確認ください。
